# Global Success — Digital Interactive Coursebook 📘

Nền tảng Sách Giáo Khoa Tiếng Anh Tương Tác Số Hóa dành cho học sinh tiểu học, bắt đầu từ bộ giáo trình **Tiếng Anh 1 Global Success** (Nhà xuất bản Giáo dục Việt Nam).

## 🌟 Tính Năng Nổi Bật
- **Trang Sách Chuẩn Sư Phạm WebP**: Số hóa 100% hình ảnh nguyên bản của sách giáo khoa, tối ưu hóa kích thước siêu nhẹ cho điện thoại và máy tính bảng.
- **Điểm Chạm Âm Thanh (Audio Hotspots)**: Nút loa tương tác nhấp nháy ghim trực tiếp lên từng từ vựng, nhân vật và đồ vật trên trang sách.
- **Phát Âm Bản Xứ (Web Speech API)**: Tốc độ đọc 0.8x chuẩn mẫu giáo dục mầm non và tiểu học.
- **Thẻ Từ Vựng Thông Minh (Vocabulary Card)**: Hiển thị từ vựng tiếng Anh to rõ, phiên âm quốc tế IPA, nghĩa tiếng Việt cùng nút nghe lại.
- **Công Cụ Quản Trị Ghim Điểm (Admin Pin Tool)**: Hỗ trợ giáo viên định vị và ghim tọa độ âm thanh trực quan ngay trên trình duyệt và xuất dữ liệu JSON tự động.

## 🚀 Công Nghệ
- Pure HTML5 / Modern CSS3 (Mobile-First, Zero Layout Shift)
- Vanilla JavaScript ES6+
- Web Speech API
